# Smart Parking Management System

## About the Project
A C++ application that demonstrates how parking spaces and vehicle records can be managed through a simple program.

## Features
- Display parking information
- Manage vehicle entries
- Track parking space availability, if implemented
- Record vehicle exits, if implemented
- Display parking records

## Technologies Used
- C++
- Data Structures

## Concepts Used
Arrays, structures or classes, loops, and conditional statements.

## How to Run
Compile the C++ source file and run the program.

## Learning Objective
To apply programming concepts to a practical parking management problem.
